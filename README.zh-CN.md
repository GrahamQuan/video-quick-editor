# Video Quick Editor

[English](README.md) | **简体中文**

一款 macOS 本地视频剪辑工具：截取视频片段、按顺序拼接、添加文字水印，也可以用聊天指令完成剪辑。

**[下载安装包](https://github.com/GrahamQuan/video-quick-editor/releases)** · 支持 Apple Silicon Mac（M 系列芯片）

## 安装与首次使用

1. 在 GitHub Releases 中展开 **Assets**，下载文件名以 `mac-arm64.dmg` 结尾的安装包。标为 **Pre-release** 的版本包含较新的功能，可能还不够稳定。
2. 打开 DMG，将 **Video Quick Editor.app** 拖入 **Applications（应用程序）**，然后启动。
3. 应用需要电脑上已安装 **FFmpeg 和 ffprobe**，安装包不包含这两个工具。如果提示缺失，在设置中选择已有工具的路径，然后点击“保存并重新检测”。
4. 在 **Settings → Language** 中选择 **简体中文**。

当前安装包尚未经过 Apple 公证。如果 macOS 提示“Apple 无法检查是否包含恶意软件”，确认安装包来自本仓库后，可前往 **系统设置 → 隐私与安全性 → 仍要打开**。

## 剪辑一个视频

1. 点击添加按钮选择视频，或将文件拖入窗口。支持 **MP4、MOV、MKV**。
2. 选中视频，拖动时间尺左右两端，设置要保留的起点和终点；也可以直接输入时间。
3. 播放预览，确认所选片段。键盘方向键可微调 0.1 秒，按住 Shift 可调整 1 秒。
4. 按需添加水印、选择输出位置，然后提交导出。
5. 在“导出”页查看进度，完成后打开视频或在 Finder 中显示。

默认导出为兼容性较好的 **MP4**，保存到“下载”文件夹。默认文件名类似 `2026_09_07--22_30_45.mp4`，重名时自动添加后缀，不会直接覆盖已有文件。

## 拼接多个视频

导入多个视频后进入“组合”，确认参与拼接的片段并调整顺序。逐个设置保留的时间范围，再提交组合导出。

不同尺寸的视频会按比例缩放，必要时补黑边。提交后可以继续编辑；已提交的任务保留当时的剪辑设置，多个任务依次执行。

任务入队后会显示提示，3 秒后自动消失，也可以手动关闭。

## 添加文字水印

选中片段，打开文字水印开关并输入内容。

- 默认位置为 **左下角**，字号为 **24**。
- 默认使用可用的系统字体，通常无需额外安装字体；也可以手动选择。
- 位置、字号、边距和黑色描边均可调整；描边设为 0 即可关闭。
- 每个片段的水印独立设置，复制片段会一并复制其水印。

播放器中的水印是近似预览。使用“预览导出画面”确认实际效果；如提示缺少字形或文字超出画面，可更换字体、缩小字号或缩短文字。

## 用 AI 聊天剪辑

手动剪辑无需 API key。使用 AI 前，在 **设置 → 模型配置** 添加模型，填写服务商提供的 **Base URL、Model ID 和 API key**，保存并测试连接，然后打开右上角聊天面板。

可以直接描述需求：

> 第一个视频保留 5 到 20 秒，第二个保留前 10 秒，拼接后加上“旅行记录”水印，最后导出。

也可以把本地路径和剪辑要求一起发给 Agent：

```text
视频剪辑和拼接
1. "/Users/you/Movies/a.mp4"，保留第 1 秒到第 3 秒
2. "/Users/you/Movies/b.mp4"，保留第 5 秒到第 10 秒
剪辑完成后拼接，最后输出视频
```

将示例路径替换为自己的文件路径；包含空格时请保留引号。应用会先导入文件，再继续执行剪辑。

- 只想导入文件时，粘贴路径并点击“导入路径”，无需配置模型。
- 支持文件夹路径：仅导入第一层视频，按文件名自然排序，每次最多 100 个。
- 可保存多个模型，在聊天顶部切换；切换后从下一轮回复生效。
- “停止回复”停止 AI 后续操作；取消已经提交的导出，请到“导出”页操作。
- “清空聊天”清除消息和对话上下文，保留当前剪辑内容、模型设置和导出任务。

视频在本机处理。使用在线模型时，会发送文字指令、文件显示名和必要的媒体信息，不上传视频、音频或预览图；API key 在本机加密保存。

## 更新应用

每次推送 `main`，检查通过后自动发布一个末位递增的版本，例如 `0.1.1`、`0.1.2`。旧的 `-main.N` 预发布包仍保留在发布历史中。

在 **设置 → 应用更新 → 检查更新** 中查看新版。正式版默认检查正式版；想体验开发版本，可以勾选“包含预发布版本”。

发现新版后，点击“打开 GitHub 下载页”，下载 DMG。等待导出完成，退出应用，再替换 Applications 中的旧版。设置和模型配置会保留。

应用不会自动下载安装。旧版若没有更新入口，可直接访问 [GitHub Releases](https://github.com/GrahamQuan/video-quick-editor/releases)。

## 常见问题

| 问题                                   | 处理方式                                                                                   |
| -------------------------------------- | ------------------------------------------------------------------------------------------ |
| 提示缺少 FFmpeg / ffprobe              | 安装工具或在设置中选择已有工具，再重新检测；若提示缺少某项能力，需要使用包含该能力的版本。 |
| 视频无法预览                           | 尝试生成“预览副本”；导出仍使用原视频。                                                     |
| 想更快导出                             | 可选择快速复制模式（copy），但不支持水印，裁剪边界也可能有偏差。通常保留默认模式即可。     |
| HDR、10-bit 或带旋转信息的视频无法导出 | 当前重编码暂不支持这些输入，请先转换为普通 SDR 视频。                                      |
| 关闭应用后任务或聊天不见了             | 剪辑、聊天和导出队列仅保留在当前会话。退出前请完成需要的导出。                             |

当前不支持 Intel Mac、Windows、Linux，也不提供多轨编辑、转场或字幕编辑。额外音轨、字幕和章节不会保留到导出文件中。

## 从源码运行

仅开发者需要 Node.js 22.12+ 和 pnpm 10.33.0：

```bash
pnpm install
pnpm dev
```

构建安装包使用 `pnpm package`。实现与开发约定见 [AGENTS.md](AGENTS.md) 和 [规格文档](specs/agent-video-editing.md)。
