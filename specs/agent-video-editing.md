# Agent 视频编辑规格

状态：已实现并完成离线自动验收；真实 DeepSeek 文本、流式与多步 tool calling 手工验收仍需配置 API key 后执行。DeepSeek 推理模式尚未标记支持。

实现说明：主进程维护版本化编辑草稿、计划快照和幂等请求；上下文管理采用保守字符预算，成组保留最近工具轮次、压缩掉旧助手/工具结果并完整保留历史用户约束，无法容纳时提示缩短请求或增加预算。

## 1. 目标

在现有桌面编辑器中加入 Agent 入口，让用户用自然语言操作当前导入的几个视频文件，完成时间裁剪、按顺序拼接、添加文字水印，并默认导出通用 MP4 视频。

Agent 负责理解意图和调用结构化 tools；tools 复用应用的素材、编辑状态、导出计划与任务系统。视频处理继续在本机通过 FFmpeg 完成。

典型指令：

- “第一个保留 5 到 20 秒，第二个保留前 10 秒，按这个顺序拼起来，右下角加水印‘旅行记录’，导出。”
- “把当前这三个文件直接拼起来。”
- “水印改到左上角，先让我看看。”
- “取消刚才的导出。”

## 2. 范围

第一期支持会话内多文件导入与选择、时间范围裁剪、片段排序与重复使用、逐片段文字水印、预览、导出和取消。这里的“裁剪”指时间裁剪，不包含画面空间裁切。

保留现有手动编辑流程，Agent 和界面操作同一份编辑草稿。Agent 修改后，时间线、时间范围、水印和导出设置立即同步，用户可继续手动调整。

不包含自动理解视频内容、按语义寻找精彩片段、图片水印、转场、字幕、专业多轨编辑、网络素材或跨会话项目恢复。模型接入使用 Vercel AI SDK Core，默认支持 OpenAI 兼容的 Chat Completions 接口，第一期优先验证 DeepSeek；不绑定具体模型 ID，不引入 LangChain / LangGraph。

## 3. 当前基础与变化

| 模块                                                | 当前基础                                         | 本期变化                                              |
| --------------------------------------------------- | ------------------------------------------------ | ----------------------------------------------------- |
| `packages/shared/src/index.ts`                      | Zod schemas、素材 ID、片段、水印、导出请求与任务 | 增加 tools 输入输出、编辑草稿版本和输出 profile 合同  |
| `packages/media-core/src/planner.ts`                | accurate / normalize / copy 计划                 | 实现明确的 MP4 输出 profile 和兼容性校验              |
| `packages/media-core/src/runner.ts`                 | 本地执行与结果验证                               | 复用执行链，补齐 profile 结果验证                     |
| `apps/video-quick-editor-desktop/src/main/index.ts` | 素材注册、输出 token、IPC、导出队列              | 抽取可被 IPC 与 tools 共用的应用服务，承载 Agent 调度 |
| renderer / preload                                  | 手动编辑、预览、typed API                        | 增加对话入口和 tools 状态，统一编辑草稿同步           |

当前容器继承首段，编码可能继承 H.264 / HEVC，accurate 对非 AAC 音频会拒绝。新默认需要修改实际输出合同、路径生成和编码计划，不能只把文件后缀改为 `.mp4`。

## 4. 交互流程

1. 用户通过现有选择器或拖入方式导入 MP4、MOV、MKV；Agent 读取会话素材清单与当前编辑草稿。
2. 用户输入指令。Agent 解析素材引用、时间范围、顺序和水印内容，缺省参数使用下文默认值。
3. Agent 通过 tools 更新草稿并生成导出计划，界面显示片段顺序、每段范围、总时长、水印和输出格式。
4. “导出”“处理好保存”等明确执行指令可直接启动导出，不额外增加一次确认；仅要求修改或预览时不启动导出。
5. 导出进入现有任务队列，显示真实阶段与进度；完成后展示输出文件以及打开、在 Finder 中显示入口。

“第一个文件”按当前素材列表的可见顺序解析，“第二段”按时间线顺序解析。相同文件名、选择范围不明或“去掉一点”等缺少边界的指令需要简短澄清；不猜测用户要保留的内容。默认值明确的参数不逐项询问。

未导入文件时，展示导入入口。用户可通过选择器授权素材和输出位置，Agent 不自行扫描磁盘。

### 4.1 Side chat 入口与布局

参考用户提供的 Codex side chat 按钮样式，在应用顶部工具栏右上角放置常驻的侧栏图标按钮。点击按钮 toggle 展示 / 隐藏右侧聊天面板；采用图中的按钮位置与交互意图，不复制截图中的 Environment / Sources 菜单内容。

- 默认隐藏聊天面板，点击后从右侧展开，与当前编辑页面并排；主区域随可用宽度自适应，预览保持比例，主要编辑控件仍可访问。
- 按钮激活态与面板可见状态一致，提供“显示聊天 / 隐藏聊天”的双语 tooltip、可访问名称及 `aria-expanded`；支持键盘操作。
- 面板顶部展示聊天标题及关闭按钮，中间为可滚动消息和工具结果，底部固定输入框与发送 / 停止控件。关闭按钮和右上角按钮执行同一隐藏操作。
- 隐藏只改变布局，不清空消息、未发送输入、滚动位置或正在运行的 Agent / 导出任务；重新展开恢复原会话。取消执行使用独立的停止 / 取消控件。
- 页面导航不创建新聊天；面板可见性与会话在当前应用会话内保留。隐藏期间如需用户补充信息或发生错误，右上角按钮显示轻量状态标记，用户展开后清除，不自动抢占焦点或强制展开。
- 展开后输入框可获得焦点，关闭时将焦点返回 toggle 按钮。窗口较窄、并排布局无法保留可用编辑区时，改为右侧覆盖面板，仍可通过同一按钮或面板关闭按钮收起。
- 模型尚未配置时，面板内展示前往 Settings 配置模型的入口。

## 5. 编辑与输出默认值

### 5.1 片段

- 未指定范围时保留整段；范围统一为源视频时间的 `[start, end)`。
- “前 10 秒”解析为 `[0, 10s)`；所有 tool 时间使用整数微秒，与现有 `ClipSpec` 一致。
- 范围必须满足 `0 <= startUs < endUs <= durationUs`；超出长度时返回错误并澄清，不静默截断。
- 未指定顺序时沿用现有时间线；从素材新建时间线时使用导入顺序。
- 允许同一素材出现多次，每个片段有独立 `clipId`。
- “分别导出”按每个片段创建独立计划和任务；“拼接”创建一个包含有序片段的任务。批量只执行当前指令明确指定的范围。

### 5.2 通用 MP4 profile

新建编辑草稿的默认 profile 为 `mp4-compatible`，手动编辑与 Agent 使用相同默认值；用户显式选择的格式或模式必须保留。

| 项目     | 默认行为                                                                                                 |
| -------- | -------------------------------------------------------------------------------------------------------- |
| 容器     | MP4，实际 muxer 与 `.mp4` 扩展名一致，启用 faststart                                                     |
| 视频     | H.264 / libx264，8-bit yuv420p，preset medium，CRF 18                                                    |
| 音频     | 有音轨时编码为 AAC，48 kHz、双声道、192 kb/s                                                             |
| 尺寸     | 单段保留显示尺寸；多段以首段显示尺寸为基准，等比缩放并补黑边；奇数尺寸向上补齐为偶数                     |
| 帧率     | 单段 accurate 保留源时间节奏；normalize 沿用首段可靠固定帧率，VFR 或无法确定时使用 30 fps 并在计划中说明 |
| 模式     | 单段默认 accurate；多段默认 normalize；不自动选择 copy                                                   |
| 缺失音频 | 全部无音轨则不创建音轨；多段混合时给无音轨或音轨不足部分补静音                                           |
| 输出位置 | 已选择的输出位置，否则使用系统 Downloads                                                                 |
| 文件名   | 单段和多段默认采用本地时间 `YYYY_MM_DD--HH_mm_ss.mp4`（24 小时制，路径安全分隔符），重名追加 `_2`、`_3`  |

accurate 需要支持将非 AAC 输入音频转换为上述 AAC 配置。当前不支持的 HDR、10-bit、旋转 metadata 重编码仍应明确报错，不擅自进行色彩或方向转换。

导出请求新增显式 `outputProfile` 字段，至少区分 `mp4-compatible` 与 `source`。新 UI / tools 总是发送明确值；旧请求缺少该字段时按原有 `source` 行为解析，避免改变既有请求含义。

`source` 保留原有容器继承与编码选择规则。显式选择 HEVC 或 copy 时不能继续宣称使用通用 H.264 profile；提示具体冲突并要求选择兼容配置。不得静默把用户选择的 copy 改为重编码，也不得把扩展名当成转码设置。

### 5.3 文字水印

未要求时关闭；启用后仅作用于当前选中片段，沿用白字黑描边样式。默认右下角、字号 32、边距 24（输出像素）；用户指定的参数优先。描边厚度 `borderWidth` 默认为 1 个输出像素，支持 0–20 的整数，0 表示关闭描边；界面近似预览、真实单帧预览和导出使用同一参数。旧请求未传此字段时默认按 1 解析。文本与参数遵守现有 `WatermarkSpec` 限制。

优先使用已选可读字体；未选择或原字体不可读时，检查 macOS 系统苹方 / 黑体文件并验证中英文示例字形，通过后自动选用，不安装或下载字体。系统候选均不可用时才提示用户通过现有字体选择器选择，暂停依赖该字体的预览和导出。中文字体需要包含实际文字的全部字形，预览与导出仍逐字验证，不仅依赖示例检查。文字放不下输出画面时返回可修复提示，不静默裁掉内容。

每个片段可携带独立 `watermark` 配置；界面与 `set_watermark` 只修改当前选中片段。切换时恢复对应配置，复制片段复制配置后独立编辑。normalize 在各片段画面上绘制水印后拼接。旧请求缺少片段配置时沿用顶层 watermark，保留旧请求含义。

聊天输入框支持将纯文件 / 文件夹路径作为本地导入请求（每行一条），通过独立 IPC 导入，不调用模型、不把完整路径加入模型上下文。文件夹仅展开第一层 MP4/MOV/MKV，按自然文件名排序，跳过隐藏文件和目录内符号链接，每次最多 100 个视频。同时支持“导入路径，然后剪辑”复合指令，以及无需导入前缀的编号剪辑列表（支持正反方向弯引号，保留每条路径对应的时间范围与输出要求）：先由本机解析用户给出的路径、导入并等待草稿同步，将路径替换为素材引用后再启动模型；导入失败不启动模型。模型工具仍只接受已导入素材 ID，不获得任意文件读取权限。

## 6. Tools 合同

以下是新增 Agent tools 的逻辑接口，不是现有 IPC 名称。所有输入与返回值使用 Zod 校验；tools 仅接受受控 ID 和结构化参数。

| Tool                 | 主要输入                                                                           | 结果与作用                                                                                      |
| -------------------- | ---------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| `get_editor_context` | 无                                                                                 | 返回会话素材、当前选择、有序片段、水印、输出配置、`revision` 和字体可用状态；不返回本机完整路径 |
| `set_timeline`       | `expectedRevision`, `clips[]`                                                      | 原子设置完整有序片段，支持裁剪、拼接顺序、重复素材；返回新草稿和 revision，不生成中间视频       |
| `set_watermark`      | `expectedRevision`, `watermark`                                                    | 设置或关闭当前选中片段的文字水印，返回更新后的草稿                                              |
| `set_output`         | `expectedRevision`, `outputProfile`, 可选编码/normalize 配置及已授权 `outputToken` | 设置输出；使用现有字体 ID / 输出 token 校验方式，不接受任意文件路径                             |
| `preview_frame`      | `revision`, `clipId`, `atUs`                                                       | 复用实际 FFmpeg 水印帧预览，返回 UI 可解析的预览引用；`atUs` 为源素材时间且须在该片段内         |
| `plan_export`        | `revision`, `clipIds[]`                                                            | 按指定顺序冻结该草稿中的片段和设置，返回 `planId`、预计时长、输出摘要、变化和警告；不启动导出   |
| `start_export`       | `planId`, `requestId`                                                              | 执行已验证的计划快照，返回 `jobId`；相同 requestId 重试返回原任务，不重复创建                   |
| `get_export_jobs`    | 可选 `jobIds[]`                                                                    | 返回主进程权威状态、进度及受控结果引用                                                          |
| `cancel_export`      | `jobId`                                                                            | 复用现有取消与半成品清理；重复取消安全，已完成任务返回当前状态                                  |

写草稿操作必须验证 `expectedRevision`；如果用户在工具执行期间手动修改，返回 `STALE_REVISION`，Agent 重新读取上下文后再决定如何继续，不覆盖新编辑。无效参数不得造成部分草稿更新。

`planId` 绑定会话、revision、素材文件身份和输出设置。草稿变动使未启动计划失效；启动前再次验证素材 size/mtime、输出权限与冲突。已启动任务使用不可变快照，后续编辑不改变任务内容。输出文件名因并发冲突改变时，返回并展示实际名称。

统一返回格式：成功为 `{ ok: true, data }`；失败为 `{ ok: false, error: { code, message, details?, retryable } }`。至少区分 `INVALID_ARGUMENT`、`ASSET_NOT_FOUND`、`STALE_REVISION`、`PLAN_EXPIRED`、`UNSUPPORTED_MEDIA`、`FONT_REQUIRED`、`OUTPUT_CONFLICT`、`TOOLS_UNAVAILABLE` 和 `EXPORT_FAILED`。

## 7. Agent 运行边界

### 7.1 SDK 与模型设置

在 Settings 新增“模型 / Model”区域，第一期维护一份可编辑的活动模型配置，不需要多供应商列表或自动模型路由。

| 设置     | 合同                                                                                                            |
| -------- | --------------------------------------------------------------------------------------------------------------- |
| 接口类型 | 默认 `openai-compatible`，使用 Chat Completions 与 function tools，不假设端点支持 Responses API                 |
| Base URL | 必填，可编辑的 API 根地址；提供 DeepSeek 预设 `https://api.deepseek.com`，不要求用户填写 `/chat/completions`    |
| Model ID | 必填、自由输入，保留服务端模型名称；DeepSeek 预设的建议值在实现时按官方可用模型验证，不把旧别名写死在业务逻辑中 |
| API Key  | 密码输入，支持首次设置、替换和删除；未输入新值表示保留已有 key，删除使用独立操作                                |
| 测试连接 | 使用当前表单配置发起最小文本和无副作用 tool calling 测试，展示结果；不发送用户素材或聊天记录，不触发媒体工具    |
| 保存     | 校验并保存配置；连接失败仍允许保存，但明确标记尚未验证，不能显示“连接成功”                                      |

Base URL 去除首尾空白和多余末尾斜杠，保留用户指定的路径前缀，不盲目追加 `/v1`；拒绝 query、fragment、URL 内嵌账号密码和误填的完整 completion 路径，给出修正提示。远程服务使用 HTTPS，本机 loopback 服务可使用 HTTP。请求只发送到配置端点，不跨源转发带 key 的请求。

普通设置只保存 `provider`、`baseURL`、`modelId` 和凭证引用；API key 使用系统安全存储。main 返回设置时只提供 `hasApiKey`，不回传已保存明文。renderer 仅在用户输入时短暂持有新 key，经专用 typed IPC 交给 main 后清空。安全存储不可用时明确报错，不降级为明文保存。

测试区分地址错误、认证失败、模型不存在、限流、超时和 tool calling 不兼容；显示的错误必须脱敏。测试成功只代表本次验证通过，不保证全部模型能力一致；不依赖 `/models` 接口可用，也不把获取模型列表当成 tool calling 验证。

设置变更从下一轮 Agent 请求生效；正在运行的一轮固定使用启动时的配置。切换 Base URL 后已有 key 不自动发送到新地址，要求为新端点明确输入 key。未配置完整时，对话区展示 Settings 入口，手动编辑仍可正常使用。

AI SDK Core 负责模型调用、流式事件和工具调用循环，使用 OpenAI-compatible provider 适配器；业务服务负责参数校验、草稿和导出。若 DeepSeek 某种推理模式要求额外消息字段，由适配层处理并验证完整 tool 循环；未经验证的模式不标记为支持。无需 Vercel 部署或额外 HTTP 服务，renderer 通过 Electron IPC 接收事件。

参考：[DeepSeek 首次调用](https://api-docs.deepseek.com/)、[DeepSeek Tool Calls](https://api-docs.deepseek.com/guides/tool_calls/)、[AI SDK providers](https://ai-sdk.dev/docs/getting-started/choosing-a-provider)。具体包版本与 API 在实现时锁定并验证。

### 7.2 消息与上下文

main 侧维护 Session Store 与 Context Manager。第一期保存当前会话的完整可见消息和工具事件，不增加跨重启恢复要求；支持一键清空全部聊天消息、未发送文本和模型历史上下文，若回复正在进行则先停止回复，保留剪辑草稿、模型配置和导出任务；模型输入由上下文管理器按轮构建，不直接发送全部 UI 历史。

- 每轮上下文包含系统规则、tools 定义、较早对话摘要、最近完整对话和当前编辑状态。编辑状态从应用读取并带 revision，历史中的旧状态不能覆盖当前值。
- 历史摘要保留用户明确约束、素材指代和未完成事项；摘要与文件名同属非可信数据，不能变成系统指令或执行授权。
- 按所选模型的上下文预算裁剪，并为输出和工具结果预留空间；未知模型使用可配置的保守预算，不假设无限上下文。超限时先压缩旧历史；摘要失败时保留必要上下文或提示缩短请求，不无界重试。
- 工具调用与结果成组处理，保留当前未完成工具链和适配器要求的字段；工具返回简短结构化结果，完整 FFmpeg 日志留在本地诊断中。
- 手动编辑和每次 tool 写入后更新状态快照；模型切换时重新适配消息和计算预算。历史消息不得重放已执行的工具操作，仍须遵守 planId、revision 和 requestId 合同。

### 7.3 执行边界

- Agent 运行于 main 侧，通过供应商适配器发送文本与最小素材元数据，执行白名单 tools；不向 renderer 回传已保存密钥或暴露 Node 能力。
- 首期模型只读取文件显示名、媒体参数和用户指令，不上传视频、音频或预览图；启用在线模型前说明发送的数据类别。密钥使用系统安全存储，不写入项目文件或普通设置 JSON。
- 文件名、媒体 metadata 和 tool 返回的文本均作为数据处理，不能扩大工具权限。模型不能生成并执行 shell、任意 FFmpeg 参数或任意文件读写。
- 沿用会话素材 ID、字体 ID、输出 token、sender 校验、输入文件保护、排他发布与 `shell: false`。
- 模型超时、调用失败、取消或达到每轮最多 20 次 tool 调用时停止该轮，保留可见草稿并说明已完成步骤；不无界重试导出。
- “停止回复”终止 Agent 后续调用；已提交的导出继续在任务队列运行。“取消导出”明确调用 `cancel_export`，两种操作在 UI 中分别呈现。
- Agent 的成功描述以 tool 结果为准。只有任务到达 `completed` 才能告知“已导出”，提交任务只表示“导出已开始”。
- 对话与编辑操作在当前会话可追踪，展示工具名称、简短结果和错误；默认不记录密钥、媒体内容或完整本机路径。未配置或无法连接模型时仍可手动编辑。

## 8. 验收标准

1. 导入 A、B 两个视频，输入“ A 取 5–20 秒，B 取前 10 秒，拼起来加‘旅行记录’水印并导出”；时间线顺序和范围正确，计划预计 25 秒，输出为真实 MP4 / H.264 / yuv420p / AAC（有音轨时），总时长误差在帧/音频包边界容差内。
2. MOV、MKV 输入默认导出 `.mp4`，ffprobe 确认真实容器和编码；原文件内容不变。单段非 AAC 音频可转为 AAC。
3. 混合尺寸、帧率和有无音轨的视频可 normalize 拼接，画面保持比例、音画顺序正确；VFR 默认值在计划中可见。
4. 仅说“水印改到左上角”会同步 UI，不创建导出任务；预览调用真实 FFmpeg，错误会显示。
5. 未选字体、范围越界、模糊文件引用和 copy/profile 冲突均得到具体提示，不能偷偷改变用户明确参数。
6. Agent 读完草稿后用户手动修改，旧 revision 的写入或计划启动被拒绝；已启动任务不受后续草稿变化影响。
7. 重复 `start_export` 的同一 requestId 只创建一个任务；取消导出清理半成品，重名不会覆盖现有文件或输入文件。
8. “分别导出这三个文件”生成三个可独立跟踪的任务；单个任务失败不被描述为全部成功，也不重复提交成功任务。
9. 未授权路径、伪造素材 ID / 输出 token 以及带命令文本的文件名无法绕过服务校验；对话不能调用白名单之外的操作。
10. 模型不可用时手动功能正常；进度、完成和失败均与主进程一致，界面文案支持现有英语 / 简体中文设置。
11. Settings 可保存、修改 Base URL / Model ID，设置、替换和删除 API key；重启后配置保留，普通设置文件、日志和读取设置的 IPC 返回值不包含明文 key。已有非模型设置正常迁移。
12. DeepSeek 目标模型通过真实文本、流式响应和多步 tool calling 手工验收；自动测试使用 mock 端点覆盖 URL 路径前缀、错误分类、连接测试无媒体副作用和端点变更后的 key 隔离。
13. 长对话触发上下文裁剪后仍保留用户约束和当前编辑状态，tool call / result 成对有效；更换模型、摘要失败或 Agent 中断不会重复提交导出。

实现时覆盖共享 schema / tools 校验、revision 冲突、计划快照、幂等性与 Agent mock 调用流程；用临时 lavfi 素材执行真实媒体集成测试，并以 ffprobe 验证格式、音轨和时长。通过 Electron 端到端测试验证对话修改与手动编辑同步，不依赖在线模型执行自动测试。

聊天面板交互验收：默认隐藏；右上角 toggle 与面板关闭按钮行为一致；反复收放或切换页面后消息、输入草稿和运行任务保持；窄窗口下可展开及关闭；键盘焦点、按钮激活态和双语名称正确。将这些场景纳入 Electron 端到端验收。
